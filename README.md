# Mohammed Raza — Portfolio

Personal portfolio site, built to showcase full-stack and AI automation work while taking on freelance projects.

Built with Next.js, React, GSAP ScrollTrigger, and Lenis. The project also includes React Three Fiber and Three.js components, though the current page does not render a 3D scene.

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000).

## Check the build

\`\`\`bash
npm run build
\`\`\`

## Notes

- The featured project cards are placeholders.
- The LinkedIn and Vercel footer icons are visual placeholders until their profile URLs are supplied.
